# בית בישראל – דף נחיתה

דף נחיתה לעסק יזמות וניהול פרויקטים.

- `src/page.html` – תוכן הדף (עריכה כאן)
- `./build.sh` – בונה את `index.html` המלא לפרסום
- `assets/logo-original.jpg` – הלוגו המקורי (בדף הוא משורטט מחדש כ-SVG)

טקסט בסוגריים מרובעים `[...]` הוא זמני ויוחלף בפרטים אמיתיים.

## אפשרויות עיצוב (זמני)

- `src/designs/a.html`, `b.html`, `c.html` – שלוש חלופות עיצוב, נבנות ל-`design-a.html` וכו'.
- `src/switcher.html` – פס המעבר בין האפשרויות, מתווסף לכל הדפים. להסיר אחרי שנבחר עיצוב.
